## What's new

**Group Policy, as far as the directory can tell.** Open any user or computer and the row's new Policies section lays out where it sits (site, domain, and each organizational unit down to its own) and which policies reach it, in order of precedence. Enforced links, blocked inheritance, disabled links, security filtering by allow and by deny, and half-disabled policies are all worked out from the directory and each link that does not apply says why. A WMI filter is flagged rather than guessed at.

**A Policies register.** Every Group Policy Object in the domain on one page: where it is linked, whether a link is enforced or disabled, which half is switched off, whether a WMI filter is attached, and who it is filtered to. Orphans that are linked nowhere stand out. Export it as CSV.

**Plain LDAP stays honest.** Against a directory that is not Active Directory, the Stale accounts, Privileged access and Policies registers say they need Active Directory instead of running on data that is not there.

This is read from LDAP only. What a policy sets lives in SYSVOL and is not shown, and loopback, slow-link and WMI evaluation happen on the client.
