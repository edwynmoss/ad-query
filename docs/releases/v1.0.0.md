## What's new

AD Query 1.0 is the first release you install rather than unzip.

**A real installer.** Per-user setup with no administrator prompt, a Start menu entry, an optional desktop shortcut and a clean uninstall. The app icon is new too: a small directory tree, the second child in blue.

**Updates from inside the app.** AD Query checks for a newer release a few seconds after launch, every six hours while it stays open, and when the window comes back after an hour away. A newer version shows as a toast; one click downloads the signed installer, verifies it, and restarts into it. **Check for updates** lives in the Tools menu, and the running version shows in the footer.

**Housekeeping.** Every dependency security alert cleared. Tests run on every pull request. Interface copy tidied.

Everything that made AD Query useful is unchanged: read-only by design, plain-language queries over Active Directory or LDAP, any attribute as a column, accurate last logon across domain controllers, risk flags, bulk lookup from CSV or Excel, Microsoft 365 licence and sign-in enrichment, and CSV export with an evidence header.

## Install

- **Windows setup (per-user):** `ADQuery-1.0.0-x64-setup.exe`

Earlier versions were a bare executable and cannot update themselves. Install this version once; every version after it updates itself.
